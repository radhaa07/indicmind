┌─────────────────────────────────────────────────────────────────────────┐
│                    SECURITY FEATURES                                    │
└─────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────┐
    │           Time-Based Expiration                 │
    │  • OTP expires after 10 minutes                 │
    │  • Server-side timestamp validation             │
    │  • No client-side manipulation possible         │
    └─────────────────────────────────────────────────┘
                        │
                        ▼
    ┌─────────────────────────────────────────────────┐
    │           Single-Use Validation                 │
    │  • OTP marked as "used" after verification      │
    │  • Cannot be reused for multiple logins         │
    │  • Prevents replay attacks                      │
    └─────────────────────────────────────────────────┘
                        │
                        ▼
    ┌─────────────────────────────────────────────────┐
    │        Automatic Invalidation                   │
    │  • New OTP request invalidates old ones         │
    │  • Only one active OTP per email at a time      │
    │  • Reduces attack surface                       │
    └─────────────────────────────────────────────────┘
                        │
                        ▼
    ┌─────────────────────────────────────────────────┐
    │          Email Verification                     │
    │  • OTP sent only to registered email            │
    │  • Confirms email ownership                     │
    │  • No account creation without email access     │
    └─────────────────────────────────────────────────┘
                        │
                        ▼
    ┌─────────────────────────────────────────────────┐
    │        TLS/STARTTLS Encryption                  │
    │  • SMTP connection encrypted (Port 587)         │
    │  • OTP transmitted securely                     │
    │  • Man-in-the-middle protection                 │
    └─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│                  COMPARISON: Before vs After                            │
└─────────────────────────────────────────────────────────────────────────┘

    ╔═══════════════════════════════════════════════════════════════════╗
    ║                  BEFORE (Password-Based)                          ║
    ╠═══════════════════════════════════════════════════════════════════╣
    ║  User enters:       Email + Password (memorized)                 ║
    ║  Security:          Password stored (hashed)                      ║
    ║  Forgot password:   Reset flow needed                             ║
    ║  Complexity:        Password rules required                       ║
    ║  Reuse risk:        Users reuse passwords                         ║
    ║  Breach risk:       Password database valuable target             ║
    ║  User friction:     Must remember password                        ║
    ╚═══════════════════════════════════════════════════════════════════╝
                              │
                              │ MIGRATION
                              ▼
    ╔═══════════════════════════════════════════════════════════════════╗
    ║                   AFTER (OTP-Based)                               ║
    ╠═══════════════════════════════════════════════════════════════════╣
    ║  User enters:       Email + OTP (sent to email)                   ║
    ║  Security:          No password stored                            ║
    ║  Forgot password:   Not applicable (no passwords)                 ║
    ║  Complexity:        No rules needed                               ║
    ║  Reuse risk:        Each OTP is unique and time-limited           ║
    ║  Breach risk:       No valuable credential database               ║
    ║  User friction:     No memorization needed                        ║
    ╚═══════════════════════════════════════════════════════════════════╝
