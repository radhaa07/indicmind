┌──────────────────────────────────────────────────────────────────────────┐
│  METHOD 1: AUTOMATIC (EASIEST)                                           │
└──────────────────────────────────────────────────────────────────────────┘

  Double-click this file:
  
    📄 install_indian_languages.bat
  
  It will automatically install all three languages for you!


┌──────────────────────────────────────────────────────────────────────────┐
│  METHOD 2: MANUAL INSTALLATION                                           │
└──────────────────────────────────────────────────────────────────────────┘

  Open Command Prompt or PowerShell and run these commands:

  ┌────────────────────────────────────────────────────────────────────────┐
  │ Step 1: Install argostranslate (if not already installed)             │
  └────────────────────────────────────────────────────────────────────────┘
  
    pip install argostranslate


  ┌────────────────────────────────────────────────────────────────────────┐
  │ Step 2: Update package index                                           │
  └────────────────────────────────────────────────────────────────────────┘
  
    argospm update


  ┌────────────────────────────────────────────────────────────────────────┐
  │ Step 3: Install language packages                                      │
  └────────────────────────────────────────────────────────────────────────┘
  
    argospm install translate-kn_en    # Kannada → English
    argospm install translate-mr_en    # Marathi → English  
    argospm install translate-ta_en    # Tamil → English


  ┌────────────────────────────────────────────────────────────────────────┐
  │ Step 4: Verify installation                                            │
  └────────────────────────────────────────────────────────────────────────┘
  
    argospm list
    python test_offline_translation.py

  Tamil:    ~50-100 MB
  ──────────────────────
  Total:    ~150-300 MB


┌──────────────────────────────────────────────────────────────────────────┐
│  HOW IT WORKS                                                            │
└──────────────────────────────────────────────────────────────────────────┘

  1. Upload a Kannada/Marathi/Tamil contract
     ↓
  2. System tries LLM translation first (Gemini/Ollama)
     ↓
  3. If LLM unavailable → Uses offline translation automatically
     ↓
  4. Contract analyzed normally
